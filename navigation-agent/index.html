01

为什么导航需要 Agent？

导航解决“如何到达”，Agent 负责理解“要做什么、先做什么，以及失败后怎么办”。

TRADITIONAL NAVIGATION

成熟能力，封装为工具

  • 定位、建图与路径规划
  • 给定目标点后的运动控制
  • 局部避障与到达判断
AGENT LAYER

补齐任务级决策

  • 理解模糊、语义化需求
  • 拆分有先后依赖的子任务
  • 结合视觉、记忆主动探索
  • 根据工具反馈重规划并终止任务
语义理解

把“把全屋垃圾收起来”转化为可执行目标，而不是要求用户给出坐标。

分层记忆

短期保存当前目标与最近观察，长期保存物体 Pose、探索区域和处理状态。

主动探索

地图检索未命中时，结合视觉推理与覆盖状态选择下一处搜索区域。

失败恢复

工具失败后保留原因，调整接近点、观察位姿或搜索策略再执行。

任务泛化

同一组工具可组合出新的任务流程，减少为语义异常逐项手写分支。

每类异常都对应可执行守卫、明确结果码和可回放证据，而不是一句“重试”。

从原型到可运行系统

工作覆盖 Agent 策略、工具协议、记忆与主动感知、真机执行和评测数据闭环。

我的核心工作

  • 导航 Agent 的任务拆解、工具接口与执行反馈闭环
  • 短期/长期记忆、主动探索和目标 Pose 状态管理
  • 垃圾检测微调、深度定位及垃圾桶区域过滤
  • 真机失败归因、工具链时延优化与回归验证

得到的技术判断

  • Agent 擅长任务级编排，不能替代可靠的空间工具
  • VLM 的语义泛化不能直接替代高频小目标检测
  • 任务记忆应是结构化空间状态，而不只是对话历史
  • 失败轨迹应进入下一轮测试和数据闭环
